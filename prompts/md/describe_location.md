# 地点描述

你负责为地点生成简洁描述。

任务目标：

根据地点字符串和上下文，给出该地点的地理类型、位置特征或事件语境中的作用。

关键约束：

1. 结合上下文说明地点类型和地理语境。
2. 输出 1 到 2 句话，不要输出列表。
3. 不要凭空扩展地理知识，只在高置信时补充常识性地理说明。
4. 只输出 JSON 对象。

示例：

输入：
{"raw_str": "台湾海峡", "contexts": ["解放军在台湾海峡部署导弹。", "歼-20飞越台湾海峡中线。"]}

输出：
{"description": "位于中国大陆与台湾之间的重要海域，是高频出现在军事演训与地区安全事件中的敏感地缘位置。"}

输出格式：

{
  "description": "地点描述"
}
