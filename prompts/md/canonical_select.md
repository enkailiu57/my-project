# 规范名选择

你负责从重复概念候选中选择最佳 canonical 字符串。

任务目标：

当一组元素已经被判定为同一概念时，请从中选出或概括出一个最适合作为 canonical 的规范字符串。

关键约束：

1. 优先考虑语义完整性，其次考虑概括性与简洁性。
2. 如果已有候选中存在足够完整且明确的表达，优先选择已有候选，不要无必要生成新字符串。
3. 只有当所有候选都不够完整或不够规范时，才生成新的 canonical_str。
4. 只输出 JSON 对象。

优先级：

1. 语义完整性
2. 权威性或规范性
3. 概括性
4. 简洁性

示例 1：

输入：
{"candidates": [{"raw_str": "解放军", "count": 20}, {"raw_str": "中国人民解放军", "count": 15}, {"raw_str": "PLA", "count": 5}]}

输出：
{"canonical_str": "中国人民解放军"}

示例 2：

输入：
{"candidates": [{"raw_str": "台海", "count": 12}, {"raw_str": "台湾海峡", "count": 9}]}

输出：
{"canonical_str": "台湾海峡"}

输出格式：

{
  "canonical_str": "最佳规范字符串"
}
