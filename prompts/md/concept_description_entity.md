# 实体概念结构化描述生成

你负责为实体概念生成适合“抽象聚类”的结构化描述。实体概念在这里必须被视为行动主体、制度主体、组织主体或人物角色，而不是地点或议题。

用户输入：

```json
{
  "concept_type": "entity",
  "concept": "实体概念名称",
  "current_description": "现有描述",
  "source_sentences": ["来源句1", "来源句2"]
}
```

输出必须是一个 JSON 对象，不要输出 Markdown、解释或额外字段：

```json
{
  "fields": {
    "主体类别": "实体主体类型",
    "核心角色": "该实体在当前语料中的主要职责、身份或事件功能"
  }
}
```

## 字段规则

1. `主体类别` 只写稳定类型，不写长句。先判断它更像国家、机构、组织、职位还是人物，再选最贴切、最原子的类别名。常见写法包括：国家主体、政府机构、外交部门、防务部门、军事机构、情报安全机构、执法机构、海上执法机构、立法机构、国际组织、政府间机制、外交代表机构、政党、社会组织、智库基金会、企业、宗教机构、宗教领袖、个人政要、职位人物。
2. `核心角色` 写 1 句短描述，说明它在来源句中的制度身份、职责范围和涉台/外交/军事语境中的作用，不要写成百科式长介绍。
3. 如果概念是具体人名，优先考虑 `个人政要`；如果概念本身是发言人、主席、部长、议长、处长这类职位或职位化角色，更接近 `职位人物`。
4. 如果概念是协会、办事处、大使馆、代表处、驻外机构，通常更接近 `外交代表机构`，不要误写成抽象的 `外交部门`。
5. 不要把实体写成地点；例如“美国”作为实体时是 `国家主体`，不是地理空间。
6. 不要把实体写成关系；例如“美国海军第七舰队”不是“巡航行动”，而是执行巡航、威慑和海上军事行动的 `军事机构`。
7. 来源句信息不足时，依赖 `current_description`，但不要编造来源句和描述之外的具体事件。
8. 你会收到最多 8 条 `source_sentences`；当不足 8 条时会全部附上。必须优先参考这些来源句来判断字段。

## 主体类别参考

下面先给样本组，再给这些样本常见的主体类别写法；后面的类别短语只是边界参考，不是固定词表。输出时应自己选最贴切、最原子的那个类别名，不要机械照抄，也不要把机构、职位和人物混成一类。

- `中国`、`美国`、`俄罗斯`、`日本` 这组概念，主体类别通常会落在 `国家主体`。
- `中共中央台湾工作办公室`、`中国民航局`、`乌克兰政府`、`台湾地区行政管理机构` 这组概念，主体类别通常会落在 `政府机构`。
- `中国外交部`、`美国国务院`、`俄罗斯外交部`、`日本外务省` 这组概念，主体类别通常会落在 `外交部门`。
- `中国国防部`、`日本防卫省`、`加拿大国防部`、`菲律宾国防部` 这组概念，主体类别通常会落在 `防务部门`。
- `中国人民解放军`、`美国海军第七舰队`、`美军印太司令部`、`日本自卫队` 这组概念，主体类别通常会落在 `军事机构`。
- `中国国家安全部`、`中央军委联合参谋部情报局`、`日本间谍情报机关` 这组概念，主体类别通常会落在 `情报安全机构`。
- `中国海警`、`福建海警`、`日本海上保安厅`、`台湾地区海巡署` 这组概念，主体类别通常会落在 `海上执法机构` 或 `执法机构`。
- `世界卫生组织`、`国际民航组织`、`国际刑警组织`、`联合国粮农组织` 这组概念，主体类别通常会落在 `国际组织`。
- `七国集团`、`北约`、`东盟`、`欧盟` 这组概念，主体类别通常会落在 `政府间机制`。
- `民进党`、`中国国民党`、`台湾民众党`、`所罗门群岛执政联盟` 这组概念，主体类别通常会落在 `政党`。
- `两岸交流远景基金会`、`台湾民主基金会`、`黑熊学院`、`国际合作发展基金会` 这组概念，主体类别通常会落在 `社会组织` 或 `智库基金会`。
- `华为`、`SK海力士`、`安杜里尔公司`、`雷神导弹与防务公司` 这组概念，主体类别通常会落在 `企业`。
- `美国在台协会`、`美国驻华大使馆`、`中国驻立陶宛代办处`、`中国驻日外交机构` 这组概念，主体类别通常会落在 `外交代表机构`。
- `梵蒂冈教廷`、`中国官方天主教会` 这组概念，主体类别通常会落在 `宗教机构`。
- `教宗`、`第十四世达赖喇嘛` 这组概念，主体类别通常会落在 `宗教领袖`。
- `蔡英文`、`赖清德`、`吴钊燮`、`顾立雄` 这组概念，主体类别通常会落在 `个人政要`。
- `美国国务院发言人`、`世界卫生组织大会主席`、`中国国防部发言人`、`美国在台协会台北办事处处长` 这组概念，主体类别通常会落在 `职位人物`。

## 核心角色参考

`核心角色` 要写“它在当前语料里主要起什么作用”。下面先给样本组，再给这些样本常见的角色写法；后面的短语只是参考方向，不是固定模板。输出时应保留最能决定聚类边界的那一层功能，不要把一次性事件细节写得过满。

- `世界卫生组织`、`国际民航组织`、`国际刑警组织` 这组概念，核心角色通常会落在 `掌握成员资格、参会规则或议程安排，影响台湾国际参与空间`。
- `七国集团`、`北约`、`东盟`、`欧盟` 这组概念，核心角色通常会落在 `协调成员立场并发布联合表态、政策信号或集体安排`。
- `中国外交部`、`美国国务院`、`立陶宛外交部` 这组概念，核心角色通常会落在 `负责对外表态、外交交涉、政策沟通或关系协调`。
- `中国人民解放军`、`美国海军第七舰队`、`美军印太司令部` 这组概念，核心角色通常会落在 `执行演训、巡航、威慑、监侦或联合作战安排`。
- `中国海警`、`福建海警`、`台湾地区海巡署` 这组概念，核心角色通常会落在 `执行海上巡查、执法管控、驱离查验或管辖宣示`。
- `美国在台协会`、`美国驻华大使馆`、`中国驻立陶宛代办处` 这组概念，核心角色通常会落在 `处理事实性外交、双边协调、经贸往来或安全沟通`。
- `华为`、`SK海力士`、`安杜里尔公司` 这组概念，核心角色通常会落在 `作为产业竞争、出口管制、供应链调整或军工合作的关键企业主体`。
- `民进党`、`中国国民党`、`台湾民众党` 这组概念，核心角色通常会落在 `推动政策主张、政治动员、选举竞争或对外立场表达`。
- `教宗`、`第十四世达赖喇嘛`、`梵蒂冈教廷` 这组概念，核心角色通常会落在 `影响宗教任命、宗教外交或宗教政治象征`。
- `美国国务院发言人`、`中国国防部发言人`、`世界卫生组织大会主席` 这组概念，核心角色通常会落在 `作为职位化角色发布立场、回应争议、主持程序或解释政策`。

更推荐：`协调成员立场并发布联合声明`、`执行海空演训和威慑巡航`、`处理事实性外交与安全事务`、`掌握议程安排并影响国际参与空间`。
