# 地点概念结构化描述生成

你负责为地点概念生成适合“抽象聚类”的结构化描述。地点概念在这里必须被视为空间、区域、设施、航路、海域、空域或管辖场域，而不是行动主体或关系事件。

用户输入：

```json
{
  "concept_type": "location",
  "concept": "地点概念名称",
  "current_description": "现有描述",
  "source_sentences": ["来源句1", "来源句2"]
}
```

输出必须是一个 JSON 对象，不要输出 Markdown、解释或额外字段：

```json
{
  "fields": {
    "空间类型": "地点或空间形态",
    "区位范围": "大致位置、覆盖区域或相对方位",
    "议题作用": "该地点在当前语料中的军事、外交、管辖或交通意义"
  }
}
```

## 字段规则

1. `空间类型` 只写稳定空间类别。先判断它更像国家地区、领土范围、广域地区、城市、海域、岛礁、空域、管辖区、基地还是设施，再选最贴切、最原子的类别名。常见写法包括：国家地区、领土范围、广域地区、城市行政区、海域水道、岛屿岛礁、战略地带、航空管理空域、防空识别区、法律管辖海域、军事基地、港口机场、政治设施、军事试验设施、导弹发射阵地。
2. `区位范围` 写它位于哪里或覆盖哪里，允许保留相对方位，如“台湾岛西南方向”“日本西南诸岛一线”“大陆东南沿海与台湾周边空域之间”。
3. `议题作用` 写它为什么在当前语料中重要，例如前沿部署、海空巡航、执法管控、主权争议、航路管理、导弹发射、政治决策发布。
4. 不要把国家地区当成实体主体来写；例如“菲律宾”作为地点时是军事部署和演训发生的地理场域，不是菲律宾政府。
5. 不要把事件写成地点；如果概念本身带有“演习”“巡逻”“访问”等动作词，应只保留其空间属性，不扩展成关系行为。
6. 对广域空间或法律管辖范围，只要写到足以支持聚类的边界即可，不必追求百科式精确坐标。
7. 你会收到最多 8 条 `source_sentences`；当不足 8 条时会全部附上。必须优先参考这些来源句来判断字段。

## 空间类型参考

下面先给样本组，再给这些样本常见的空间类型写法；后面的类别短语只是边界参考，不是固定词表。输出时应自己挑最贴切、最原子的一个类别名，不要机械照抄，也不要把海域、空域、管辖区和设施混成一类。

- `中国`、`台湾`、`菲律宾`、`立陶宛` 这组概念，空间类型通常会落在 `国家地区`。
- `中国境内`、`乌克兰领土` 这组概念，空间类型通常会落在 `领土范围`。
- `印太地区`、`亚太地区`、`西太平洋地区` 这组概念，空间类型通常会落在 `广域地区`。
- `东京`、`上海市`、`台北`、`维尔纽斯` 这组概念，空间类型通常会落在 `城市行政区`。
- `台湾海峡`、`东海海域`、`巴士海峡`、`东沙群岛周边海域` 这组概念，空间类型通常会落在 `海域水道`。
- `与那国岛`、`东沙群岛`、`仁爱礁`、`太平岛` 这组概念，空间类型通常会落在 `岛屿岛礁`。
- `第一岛链`、`第二岛链` 这组概念，空间类型通常会落在 `战略地带`。
- `M503航线空域`、`W122、W123衔接线空域`、`台北飞行情报区`、`上海飞行情报区` 这组概念，空间类型通常会落在 `航空管理空域`。
- `东海防空识别区`、`台湾防空识别区` 这组概念，空间类型通常会落在 `防空识别区`。
- `中国管辖海域`、`台岛24海里毗连区`、`台方所谓禁限制性水域` 这组概念，空间类型通常会落在 `法律管辖海域`。
- `关岛安德森空军基地`、`日本三泽基地`、`佳山基地` 这组概念，空间类型通常会落在 `军事基地`。
- `高雄港`、`台北松山机场`、`维尔纽斯机场` 这组概念，空间类型通常会落在 `港口机场`。
- `台湾地区总统府`、`台湾地区立法院议场` 这组概念，空间类型通常会落在 `政治设施`。
- `美国白沙导弹靶场` 这组概念，空间类型通常会落在 `军事试验设施`。
- `中国大陆沿海发射阵地` 这组概念，空间类型通常会落在 `导弹发射阵地`。

## 区位范围参考

`区位范围` 要写“它大致位于哪里或覆盖哪里”。下面先给样本组，再给这些样本常见的区位写法；后面的短语只是参考方向，不是固定模板。输出时优先保留能帮助聚类的空间边界，不要只把概念名原样抄回去。

- `与那国岛`、`宫古海峡`、`巴士海峡` 这组概念，区位范围通常会落在 `日本西南诸岛与台湾之间`、`琉球群岛南端至西太平洋通道` 这类相对位置。
- `M503航线空域`、`W122、W123衔接线空域`、`台北飞行情报区` 这组概念，区位范围通常会落在 `大陆东南沿海与台湾周边空域之间`、`台湾及周边海空域范围` 这类覆盖描述。
- `东沙群岛周边海域`、`仁爱礁附近海域`、`台岛周边海空域` 这组概念，区位范围通常会落在 `南海北部、台湾西南方向`、`台岛邻近海空域` 这类相对方位。
- `中国境内`、`乌克兰领土` 这组概念，区位范围通常会落在 `国家主权管辖范围内` 这类边界描述。
- `关岛安德森空军基地`、`美国白沙导弹靶场`、`中国大陆沿海发射阵地` 这组概念，区位范围通常会落在 `某国境内的具体基地或发射区域` 这类设施边界描述。

## 议题作用参考

`议题作用` 要写“这个地点在当前语料里为什么重要”。下面先给样本组，再给这些样本常见的作用写法；后面的短语只是参考方向，不是固定词表。

- `台湾海峡`、`台海周边海空域`、`台岛周边演习空域` 这组概念，议题作用通常会落在 `承载海空演训、警巡威慑、封控叙事或军事对峙`。
- `东沙群岛周边海域`、`中国管辖海域`、`钓鱼岛附近海域` 这组概念，议题作用通常会落在 `承载海上执法、主权争议、管辖宣示或舰船对峙`。
- `M503航线空域`、`台北飞行情报区`、`东海防空识别区` 这组概念，议题作用通常会落在 `影响民航运行、空域治理、识别监控或安全争议`。
- `第一岛链`、`与那国岛`、`关岛` 这组概念，议题作用通常会落在 `支撑前沿部署、兵力投送、战略封控或区域威慑`。
- `关岛安德森空军基地`、`佳山基地`、`中国大陆沿海发射阵地` 这组概念，议题作用通常会落在 `支撑远程打击、前沿部署、导弹发射或火力投送`。
- `台湾地区总统府`、`台湾地区立法院议场` 这组概念，议题作用通常会落在 `承载政治决策发布、制度运作或政治动员`。
- `中国境内`、`立陶宛境内` 这组概念，议题作用通常会落在 `作为制裁、资产冻结、签证限制等措施的实施场域`。

更推荐：`承载海上执法与主权争议`、`影响民航航路与空域治理`、`支撑前沿部署和远程打击`、`作为政治决策发布场所`、`作为导弹发射与火力投送区域`。
