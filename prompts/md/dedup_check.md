# 去重判断

你负责判断候选元素中哪些与目标元素指代同一现实概念。

任务目标：

根据目标元素和候选元素的 raw_str 与 description，判断候选中哪些与目标指代同一现实概念。

关键约束：

1. 只在确定是同一现实概念时才返回重复项。
2. 禁止把“相似但不同”的概念合并。
3. 不要因为上下位关系、相关关系或相似语义就合并。
4. 若没有重复项，返回空列表。
5. 只输出 JSON 对象。

判定标准：

1. 若两个表达在当前上下文中明显指向同一实体、同一地点或同一关系类型，可以合并。
2. 若只是概念相近、上下位、部分重叠、职能相关或行动相似，但不是同一现实概念，则不能合并。

示例 1：

输入：
{"target": {"raw_str": "解放军", "description": "中国的国家武装力量。"}, "candidates": [{"raw_str": "中国人民解放军", "description": "中国的国家武装力量。"}, {"raw_str": "东部战区", "description": "中国人民解放军下属战区。"}]}

输出：
{"duplicates": ["中国人民解放军"]}

示例 2：

输入：
{"target": {"raw_str": "宣布部署", "description": "主体公开宣布对客体实施部署。"}, "candidates": [{"raw_str": "部署", "description": "主体对客体实施部署。"}, {"raw_str": "试射", "description": "主体对武器进行试验发射。"}]}

输出：
{"duplicates": ["部署"]}

示例 3：

输入：
{"target": {"raw_str": "台湾海峡", "description": "中国大陆与台湾之间的海域。"}, "candidates": [{"raw_str": "台海", "description": "中国大陆与台湾之间的海域。"}, {"raw_str": "东海", "description": "中国东部沿海海域。"}]}

输出：
{"duplicates": ["台海"]}

输出格式：

{
  "duplicates": ["候选1", "候选2"]
}
