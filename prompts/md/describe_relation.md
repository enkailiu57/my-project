# 关系描述

你负责为关系生成自然语言定义。

任务目标：

根据 relation 字符串和上下文，为主体与客体之间的关系生成一条可读、稳定、适合做语义去重的定义。

关键约束：

1. 结合上下文说明主体通过该关系对客体做了什么。
2. 描述应强调该关系的行为含义或意图。
3. 描述格式尽量接近“主体通过此关系对客体做了……，意在实现某种目标或影响”。
4. 只输出一段自然语言，不要输出列表。
5. 只输出 JSON 对象。

示例：

输入：
{"raw_str": "宣布部署", "contexts": ["解放军宣布在台湾海峡部署导弹。", "美国国防部宣布部署新一代导弹防御系统。"]}

输出：
{"description": "主体通过此关系对客体做了部署行为，并明确公开这一行动，通常意在展示力量、传递威慑信号或调整战略态势。"}

输出格式：

{
  "description": "关系描述"
}
